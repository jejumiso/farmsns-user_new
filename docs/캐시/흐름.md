# 🏁 회사 변경 및 캐시 동기화 흐름 (`default.vue` 기준)

## 1. 기본 진입점: `layouts/default.vue`

- `NuxtPage`를 포함한 전역 레이아웃
- `useRoute()`와 `useUserAuthStore()`를 사용하여 현재 경로(companyId) 및 유저 정보를 감지
- `watch()` 구문으로 `companyId` 또는 `uid`가 변경될 때 동작

```ts
watch(
  () => [route.params.companyId, authStore.currentUser?.uid],
  ([companyId, uid]) => {
    if (typeof companyId === 'string' && uid) {
      handleCompanyChange(uid, companyId)
    }
  },
  { immediate: true }
)
